# 游戏设计文档

> 写代码之前先把规则想清楚。这是你第一次练习「先设计、后编码」。

## 1. 核心玩法

- 蛇在网格上持续前进，玩家用方向键控制上下左右。
- 吃到食物：蛇身长度 +1，分数 +10。
- 撞到墙壁或自己的身体：游戏结束。
- 成绩可以提交到排行榜。

## 2. 状态机

先画状态机，再写代码。想清楚有哪些状态、怎么切换，后面的代码就只是填空。

```
        ┌───────────────────── 按 R ────────────────────┐
        │                                               │
        v                                               │
      READY ──按空格──> RUNNING ──按 P──> PAUSED        │
                           │  ^              │          │
                           │  └───按 P───────┘          │
                           │                            │
                           v                            │
                        GAME_OVER ─────────────────────┘
```

| 状态 | 含义 | 可以做什么 |
| --- | --- | --- |
| `READY` | 等待开始 | 按空格开始游戏 |
| `RUNNING` | 游戏进行中 | 方向键控制，按 P 暂停 |
| `PAUSED` | 暂停 | 按 P 继续 |
| `GAME_OVER` | 本局结束 | 按 R 重开 |

## 3. 数据结构

```
蛇身      = 坐标队列，头部在队首
每走一步  = 头部入队；如果这一步没吃到食物，尾部出队

食物      = 一个随机坐标，必须落在空白格上（不能生成在蛇身上）

方向      = 当前方向 + 下一步方向（两个变量，不是一个！）
分数      = 吃到食物次数 × 10
```

### ⚠️ 为什么方向要存两个变量

如果只有一个 `direction` 变量，玩家在一帧之内快速按「右 → 下」两次，蛇会瞬间反向，判定为撞到自己直接死亡。

解决办法：`currentDirection` 每帧真正移动时使用，`nextDirection` 记录玩家输入。每帧结束时 `currentDirection = nextDirection`，并且**禁止「下一步方向」与「当前方向」相反**。

这个坑值得你亲手踩一次再修——比看十遍解释都记得牢。

## 4. 界面设计

### 终端版（M1）

用字符画格子：

```
####################
#                  #
#      @@@*        #      @ = 蛇身    * = 食物
#        @         #      # = 墙壁
#                  #
####################
分数: 30   长度: 4
```

### 网页版（M2）

- 尺寸：20 × 20 网格，每格 24px，画布 480 × 480
- 顶部：分数、长度、最高分
- 底部：开始 / 暂停按钮
- 游戏结束时弹出面板，可以输入名字提交分数

## 5. 系统架构

```
┌──────────────────────┐
│   浏览器（前端）       │   HTML + CSS + Canvas + 原生 JS
│   game.js 游戏循环    │
└──────────┬───────────┘
           │ fetch / HTTP JSON
           v
┌──────────────────────┐
│  Node.js + Express   │   REST API
│      server.js       │   POST /api/scores      提交分数
│                      │   GET  /api/scores/top  查询排行榜
└──────────┬───────────┘
           │
           v
┌──────────────────────┐
│   SQLite 数据库       │  玩家名、分数、时间戳
└──────────────────────┘

         ┌────────────────────────────┐
         │  Python 工具链（独立进程）   │
         │  · stats.py      分数统计   │
         │  · auto_player.py AI 自动玩 │
         └────────────────────────────┘
```
